Stock Lot Inventory Report

This module allows you to view inventory by lot by providing a location list and a date range.

Configuration

  • No configuration needed

Usage

To use this module, you need to:

  • Select the Inventory app
  • Select the "Reporting" button
  • Select the "Inventory Report by Lot" button
  • A wizard will open where you should enter the following:
    • List of locations
    • Start date(if left blank consider the oldest date in the system)
    • End date(if left blank consider today)
  • You can filter the list of records by any of the available columns
  • Click the button at the bottom to export all records
